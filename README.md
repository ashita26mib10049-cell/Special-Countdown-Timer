# Special Countdown Timer

A Python Tkinter-based countdown timer with a simple graphical user interface.

## Features

- Set countdown time in seconds
- Start the countdown
- Pause and resume the timer
- Reset and stop the timer
- Display remaining minutes and seconds
- Shows "Time's up!" when the countdown finishes
- Input validation
- Alarm notification
- Timer history

## Technologies Used

- Python
- Tkinter
